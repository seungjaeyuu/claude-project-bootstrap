# DEV-002: 레거시 커맨드 deprecated 표기 체계 도입

> **등록일**: 2026-05-28
> **출처**: v0.3.5 전체 감사 W4 항목
> **상태**: ✅ 완료 (v0.4.0) — `/kickoff` 통합으로 레거시 `/init`·`/init-project` 제거, deprecated 문제 해소

## 배경

v0.3.0에서 5개 커맨드가 `/init`에 통합되었으나, frontmatter에 deprecated 표기가 없어 사용자가 레거시 여부를 판단하기 어려움.

## 대상 커맨드

| 커맨드 | 통합 위치 |
|---|---|
| `/init-project` | `/init` (동일 기능) |
| `/bash-permission` | `/init --bash` |
| `/firebase-isolation` | `/init --firebase` |
| `/slim-claude-md` | `/init --slim` |
| `/doc-size-hook` | `/init --hook` |

## 작업 방향

1. Claude Code 플러그인 시스템이 `deprecated` frontmatter 키를 공식 지원하는지 확인
2. 미지원 시: description 필드에 `(Legacy — use /init instead)` 접두어 추가
3. 지원 시: `deprecated: true` + `superseded-by: init` 키 추가

## 우선순위

낮음 — 기존 커맨드가 정상 동작하며, description에 이미 "/init으로 이름 변경" 안내가 있음.
