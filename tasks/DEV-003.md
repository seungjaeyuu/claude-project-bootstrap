# DEV-003: macOS 지원 갭 보강 (Minimal tier 배포 가드레일 + 명시적 플랫폼 식별)

> **등록일**: 2026-05-31
> **출처**: v0.4.0 macOS 1급 지원 후속 (실사용 전 검증에서 발견)
> **상태**: ✅ 완료 (v0.4.1)

## 배경

v0.4.0 이 macOS 를 1급으로 올리고 `RULES_MACOS_RELEASE.md.tmpl`(서명·공증·배포)을 신설했으나, `/kickoff` 흐름이 macOS 를 일관 트리거하지 못하는 갭 4건이 잔존.

## 갭 목록

| # | 갭 | 근거 |
|---|---|---|
| 1 | Minimal tier macOS 앱이 `RULES_MACOS_RELEASE` 미수령 | Step 2a 가 Full tier 전용. macOS 배포(서명·공증)는 tier 무관 필요 |
| 2 | macOS 탐지가 추론 의존 | 명시 플랫폼 질의는 Q1a(E2E 하위)뿐. "Swift/SwiftUI" 는 iOS·macOS 공통 스택이라 자유 답변만으로 모호 |
| 3 | `claudeignore.tmpl` 에 macOS 섹션 없음 | iOS/Android/Web/Flutter만 존재. Step 3 는 "macOS 섹션 주석 해제" 를 지시 → 존재하지 않는 섹션 참조 |
| 4 | `.gitignore` 서명 키 커버리지 부족 | `*.p12` 만 존재. `RULES_MACOS_RELEASE` §🚫4 가 명시한 `.p8`/`.mobileprovision`/`*.provisionprofile` 미포함 |

## 해결 (v0.4.1)

- **A — 명시적 플랫폼 질의**: 유형 (b)/(c) 선택 시 플랫폼(iOS/macOS/Android/Flutter[/Web/백엔드]) 복수 선택. `apps/<platform>`·build/check·RULES 트리거를 결정론화. Q1a·Q1c 가 이 답을 재사용(중복 제거)
- **B — tier 무관 가드레일**: macOS 면 Minimal/Full 무관하게 `RULES_MACOS_RELEASE` 복사 (Step 2b 신설). Minimal 은 §발견 트리거 표가 없으므로 `CLAUDE.md` 📎참조에 발견 포인터 1줄 주입. 근거: 🚫 가드레일급(롤백 불가 피해)이라 "가드레일은 항상 / 도구는 tier-gated"
- **C — 템플릿 완결**: `claudeignore.tmpl` macOS 섹션 추가, `gitignore.tmpl` 서명 키 패턴 8종 기본 차단, `RULES_MACOS_RELEASE` §🚫4 `.p8` 동기화
